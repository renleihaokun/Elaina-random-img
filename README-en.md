## Elaina-random-img

Random Elaina Images  
Visit <https://elaina.haokun.me> to see beautiful Elaina

## Welcome to contribute PRs!

Convert your images to webp format, put them in the `/imgs` folder, and commit directly!

### Access Info

- Browser access to `/` will auto-redirect to `/elaina` gallery page
- API call `fetch('/')` will return a random image directly
