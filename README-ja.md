# Elaina-random-img

イレイナのランダム画像  
<https://elaina.haokun.me> にアクセスして美しいイレイナをご覧ください

## PR を歓迎します！

画像を webp 形式に変換して `/imgs` フォルダに入れ、そのままコミットしてください！

### アクセス方法

- ブラウザで `/` にアクセスすると `/elaina` ギャラリーページに自動リダイレクト
- API 呼び出し `fetch('/')` でランダム画像を直接取得
